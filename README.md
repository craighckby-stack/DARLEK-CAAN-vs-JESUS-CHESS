# ♟️ Darlek Caan vs Jesus Chess

An epic, chaotic hybrid chess game pitting the temporal insanity of Dalek Caan against the divine miracles of Jesus Christ. Includes AI personalities, custom thematic powers, and fully-narrated commentary, all driven by a multi-agent architectural system.

## 🚀 Features

- **Strategic Multi-Agent Council Chamber**: Movement is governed by a political cabinet session where pieces pitch proposals, advisors evaluate, and leaders sign off.
- **Dynamic Faction Personalities**: Every piece is a stateful agent with unique personality traits and tactical heuristics.
- **Supernatural Spell Deck**: Commanders use accumulated Power Points to cast game-changing miracles or temporal distortions.
- **Full-Stack Architecture**: Built with React and Node.js/Express, ensuring secure API interactions via server-side logic.

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, `motion`.
- **Backend**: Node.js, Express.
- **AI Engine**: Google Gemini API (server-side).

## 🚀 Getting Started

### Prerequisites

- Node.js (v20+)
- npm or bun

### Installation

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables (copy `.env.example` to `.env` and add your `GEMINI_API_KEY`).
4. Run the development server:
   ```bash
   npm run dev
   ```

### Building for Production

```bash
npm run build
npm run start
```
